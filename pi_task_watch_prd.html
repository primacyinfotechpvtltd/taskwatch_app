# PI Task Watch - Design Specifications ## 1. Visual Identity & Branding * **Primary Palette:** Vibrant Magenta/Pink theme (`#E91E63`) for headers, primary buttons, and focus states. * **State-Driven Colors:** * **Active (Tracking):** Warm Emerald Gradients (`#2ECC71` → `#27AE60`). * **Paused/Idle:** Amber Gradients (`#F39C12` → `#D35400`). * **Over-time/Alert:** Soft to Deep Reds. * **Backgrounds:** Soft pink-tinted backgrounds (e.g., pink shade 50) for grouping information. ## 2. Layout & Interaction Model * **Compact Window Design:** Optimized for a small, "always-on-top" floating window. * **Top Bar:** User info and connection status. * **Tracking Card:** Centerpiece with large, bold typography for the timer (letterSpacing: 1.2) and capsule-style buttons (30px radius). * **Bottom Section:** "Recent Activity" lists with high-density vertical layouts. * **Density over Air:** High-density layouts (8-12px fonts, tight padding) to maximize data visibility in a small space. ## 3. UI Components & Elements * **Dynamic Progress Bars:** Linear indicators that change color (Green → Orange → Red) based on time allocation. * **Shadows & Depth:** Floating card aesthetics with subtle box shadows (blurRadius: 8). * **Iconography:** Outline-style Material Icons at reduced sizes (10-12px). ## 4. Window Proportions (Desktop Widget) * **Base Dimensions:** ~480px width x ~686px height (on 1080p). * **Aspect Ratio:** 0.7 width-to-height. * **Placement:** Anchored to Bottom Right Corner with 2% margin.
